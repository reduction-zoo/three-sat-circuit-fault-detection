# Gated-formula reduction

For a legal source `φ` on `n` variables, create inputs `x₁,…,xₙ,z`. Construct a standard fan-in-two acyclic AND/OR/NOT circuit for the three-literal CNF `φ`. For an empty clause list, use `z OR NOT z` as a constant-true signal. Add final gate `w = z AND φ(x)`; make `w` the sole output and sole designated signal wire. The implementation in [`algorithm.py`](algorithm.py) caches negative-literal NOT gates and directly builds these gates in topological order. It introduces no hidden constants or unrepresented wires.

**Lemma (fault behavior).** Because `w` is the output, a stuck-at-`b` fault on `w` changes an output precisely on inputs where the fault-free value of `w` is `1-b`. The stuck-at-1 fault is always detectable: choose `z=0`. The stuck-at-0 fault is detectable precisely when some `x,z` have `z AND φ(x)=1`, equivalently when `φ` has a satisfying assignment (and then `z=1`). This includes `n=0`, empty CNF, repeated literals and tautological clauses.

**Target-output semantics.** If `φ` is unsatisfiable, stuck-at-0 is undetectable, so the unique valid target answer is `NO-SOLUTION`. If `φ` is satisfiable, both polarities are detectable, so target outputs are complete two-entry test sets. In every such valid output, its stuck-at-0 entry contains an input whose first `n` bits satisfy `φ`. Thus `G` returns source `NO-SOLUTION` on target `NO-SOLUTION`; otherwise it locates the stuck-at-0 entry and returns those first `n` bits. Its result is valid for every valid target output, irrespective of entry order or witness choice. The map reconstructs the output-wire identifier from the source in a fresh process. The target answer set is nonempty in both cases.

**Legality and cost.** Every gate refers only to earlier input or gate wires, every operator and arity is legal, and `w` is a valid output and designated wire. There are at most `n` cached NOT gates, `2m` clause OR gates and at most `m-1` conjunction gates for `m≥1`, plus the final AND. For `m=0`, there are three gates after the inputs. Thus gate count is `O(n+m)` and wire identifiers use `O(log(n+m+2))` bits. With the explicit JSON encodings, construction time and output length are `O((n+m) log(n+m+2))` up to fixed punctuation/decimal constants, hence polynomial in input length. Extraction reconstructs this circuit and scans the target output, taking time `O((n+m) log(n+m+2)+|y|)` and producing `n` bits or `NO-SOLUTION`. No solver is called by either map. The target solver may be expensive; its cost is outside the polynomial preprocessing and recovery claim. No practical speedup is claimed.

The output-fault observation is classical: Ibarra and Sahni, *Polynomially Complete Fault Detection Problems*, IEEE Transactions on Computers C-24(3), 1975, Theorem 3.4(1), characterize detectability of both output faults by nonconstancy of the circuit function. Their source formulation uses 3-DNF tautology. The explicit `z AND φ` connection from the fixed 3-CNF search source, together with total `NO-SOLUTION` recovery and the JSON implementation, is proved above rather than attributed to that theorem. Primary source: <https://www.cise.ufl.edu/~sahni/papers/faultDetection.pdf> (scanned pages 2 and 7; OCR checked 2026-09-25). This is a reconstruction of a known hardness mechanism, not a novelty claim.
